# LojaGames - Projeto Angular E-Commerce

Atividade do curso FullStack do SENAI: Desenvolvimento da página de login, vitrine home, consumo de API REST e Área Restrita de uma loja de games online.

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.0.4.

## Development server

1. Para rodar a API simulada de produtos (json-server):
```bash
npm run api
```

2. Para rodar a aplicação Angular:
```bash
npm start
```

Acesse `http://localhost:4200/`. A aplicação atualizará automaticamente caso você altere qualquer arquivo fonte.

## Build

Execute `npm run build` para compilar o projeto em produção na pasta `dist/`.
